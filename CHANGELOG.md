## First release — unreleased

- Added the Compose baseline with Caddy, PostgreSQL, Stalwart, application API, Drive and observability, plus an optional inbound worker and local AWS substitutes.
- Added account authentication, TOTP and backup codes, mailbox provisioning and suspension, an account-scoped JMAP mail API and Mail workspace.

Compose provisioning and outbound management need the corrections noted in the [documentation](docs/index.md); real-provider behavior and production recovery require validation.
