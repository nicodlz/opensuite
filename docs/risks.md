## Esuno Pass

The optional profile, storage proof, backup tooling, compatibility tests, shell
and aliases are implemented. These reduce some risks locally; they do not prove
production readiness. See the [requirements and evidence matrix](operations/pass.md#addendum-requirements-and-evidence),
[readiness gaps](operations/pass.md#production-readiness-gaps) and
[threat model](architecture/pass.md).

| Risk or unknown                                                                               | Current status and remaining work                                                                                                                                                                                                                                                                                                                                                                                                       |
| --------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Vaultwarden startup, role isolation, admin exposure, spoofed IP and shared infrastructure     | **Reduced locally:** Compose tests cover startup, PostgreSQL migrations, isolation, admin denial, proxy trust and running without app services. Real deployment and upgrade behavior remain unverified; shared Caddy, PostgreSQL superuser and host remain privileged dependencies.                                                                                                                                                     |

See [storage evaluation](operations/pass-storage.md).                                                                                                                                                     |
